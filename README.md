# Logo Design Brief

A questionnaire to send clients before starting a logo project. Clients pick logos they like
(grouped by style), choose accent colors, then save a summary image and email it with their
copied answers.

- Page: `survey/index.html`
- Example logos: `survey/samples/`
- Published with GitHub Pages by `.github/workflows/pages.yml`:
  https://ssaksoo984-creator.github.io/logodesign-/
